# CalculaTudo

Portal de calculadoras online gratuitas, rápido, responsivo e sem cadastro.

## O que está pronto

- Página inicial premium
- Catálogo com busca e filtros por categoria
- 11 calculadoras funcionais
- Modo claro/escuro
- Layout responsivo
- Páginas Sobre, Contato, Privacidade e Termos
- Página 404
- GitHub Pages e Render preparados
- Sem anúncios ou códigos de publicidade fictícios

## Publicação

### Render

Crie um **Static Site**, conecte este repositório, deixe o **Build Command** vazio e use `.` como diretório de publicação.

### GitHub Pages

O workflow em `.github/workflows/pages.yml` publica automaticamente a branch `main`. O site detecta o caminho do projeto quando estiver hospedado em `*.github.io`.

## Antes do lançamento comercial

1. Defina o domínio definitivo.
2. Gere/atualize o `sitemap.xml` com o domínio real.
3. Configure o Google Search Console.
4. Se for usar publicidade, adicione somente os códigos oficiais da conta aprovada.
5. Coloque os dados reais de contato e revise a política de privacidade.
