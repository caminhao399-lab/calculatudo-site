Política de Privacidade

Resumo

O CalculaTudo oferece calculadoras que, nas ferramentas atuais, processam os valores diretamente no navegador. Não é necessário criar conta para usar as calculadoras.

Dados informados nas calculadoras

Os valores digitados nos campos das calculadoras são usados para realizar os cálculos no próprio navegador. O projeto não envia esses valores para um servidor como parte normal do funcionamento das ferramentas atuais.

Hospedagem e registros técnicos

O site é hospedado por um provedor de infraestrutura. Como acontece com serviços web, o provedor pode processar informações técnicas necessárias para entregar as páginas, como endereço IP, data e hora e dados do navegador, de acordo com suas próprias políticas.

Publicidade e serviços de terceiros

No momento, esta versão do site não inclui código de anúncios do Google AdSense nem ferramentas de analytics de terceiros. Se novos serviços forem adicionados, esta política deverá ser revisada antes da ativação para explicar os dados, cookies e finalidades aplicáveis.

Contato e solicitações

Para correções e sugestões, use o canal do projeto indicado na página Contato. Não envie dados pessoais desnecessários.

Atualizações

Esta política pode ser atualizada quando o site incorporar novos recursos, serviços, publicidade ou formas de tratamento de dados.
